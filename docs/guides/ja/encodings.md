## 数字とヒントの後半

数字は行優先で、0が空、9より大きい値には標準の文字を使います。印刷コードには形や制約が続く場合があります。入力の文字列はプレイヤーの値、メモはマス番号とビットです。読取は寸法と構造を検証し、見た目が合う先頭部分だけでは不十分です。

```ts
import {symbolOf,valueOfSymbol,notesOf,boxOf} from "@johnmorrisdotca/kazu";
console.log(symbolOf(10),valueOfSymbol("A"),notesOf((1<<1)|(1<<3)),boxOf(6,12));
```

## 三つのループ表現

Loopはマス周囲の頂点を結びます。ましゅとヤジリンはマス中心で、ヤジリンは塗りと矢印の方向も保持します。四角に切れは長方形、美術館は電球、縦横は線の向き、塗る種類は真偽の状態です。部屋や領域は規則の形で、任意の描画グループではありません。

盤、ゲーム、探索、描画の型を同じ種類でそろえます。最大寸法や表示するサイズが、現在の生成で作れる形より広い場合もあります。[全種類の説明](../../PUZZLES.md)と[構成](architecture.md)に詳しい形式があります。
